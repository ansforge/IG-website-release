Resource Profile: Specimen - FR Specimen Document

Official URL: https://interop.esante.gouv.fr/ig/fhir/document-core/StructureDefinition/fr-specimen-document Version: 0.1.0-ballot
Draft as of 2026-11-17 Computable Name: FRSpecimenDocument

FRSpecimenDocument est un profil utilisé pour décrire le prélèvement et l'échantillon biologique (le matériel).

Usages:

  • Refer to this Profile: DiagnosticReport - FR Diagnostic Report Document, Media - FR Media Document, Observation - FR Observation Laboratory Report Results Document and Specimen - FR Specimen Document

You can also check for usages in the FHIR IG Statistics
