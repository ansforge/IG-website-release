Modèle logique: XDM referenceIdList

URL officielle: https://interop.esante.gouv.fr/ig/pdlgc/StructureDefinition/xdmreferenceId Version: 0.1.0-ballot
Draft à date du 2026-10-20 Nom computable: XDMReferenceId

Modèle logique de referenceIdList. Cette métadonnée contient une liste d'un ou plusieurs identifiant(s) d'objet(s) associé(s) au document.Liste d'éléments de type CX du standard HL7 v2.5.

Utilisations:

  • Utilise ce/t/te Modèle logique: XDM DocumentEntry

Vous pouvez également vérifier les usages dans le FHIR IG Statistics
