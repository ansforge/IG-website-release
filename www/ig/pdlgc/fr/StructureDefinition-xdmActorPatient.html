Modèle logique: XDM ActorPatient

URL officielle: https://interop.esante.gouv.fr/ig/pdlgc/StructureDefinition/xdmActorPatient Version: 0.1.0-ballot
Draft à date du 2026-10-20 Nom computable: XDMActorPatient

Cet attribut représente l'acteur Patient.

Utilisations:

  • Utilise ce/t/te Modèle logique: XDM Author and XDM DocumentEntry

Vous pouvez également vérifier les usages dans le FHIR IG Statistics

xdmActorPatient 0..* XDMActorXDSCore(0.1.0-ballot) XDM ActorPatient

Éléments définis dans les ancêtres :xcn1, xcn2, xcn3, xcn9, xcn10, xcn13
Les instances de ce modèle logique peuvent être la cible d'une référence
xdmActorPatient.xcn1 1..1 PatId(0.1.0-ballot) Identifiant du patient. Le matricule INS du patient, tel que défini dans le cadre juridique, est à utiliser prioritairement. À défaut, un autre identifiant (ex : IPP du système émetteur) peut être utilisé.
Exemple General: 124018852493334
xdmActorPatient.xcn2 1..1 string Nom du patient
xdmActorPatient.xcn3 1..1 string Prénom du patient
xdmActorPatient.xcn9
xdmActorPatient.xcn9.composant2 1..1 string Valeur de l'OID de l’autorité d’affectation de l’identifiant. Identifiant de l’autorité d’affectation de l'identifiant utilisé.
xdmActorPatient.xcn10 1..1 code Type de nom : 'D' pour les personnes physiques, 'U', pour les systèmes.
Motif requis: D (extensions allowed)
xdmActorPatient.xcn13 C 1..1 code 'NH' pour les patients identifiés par leur INS, 'PI' pour les patients identifiés par d'autres identifiants
